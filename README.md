# MindBridge

**Plataforma Web de Bienestar Emocional Asistida por Inteligencia Artificial**

> *Un puente entre la introspección diaria y la ayuda profesional.*

---

## Descripción del Proyecto

**MindBridge** es una aplicación web diseñada para cubrir el vacío existente entre el autoconocimiento personal y la terapia clínica. Funciona como un **"Diario Reflexivo Inteligente"** que utiliza procesamiento de lenguaje natural (NLP) para facilitar la introspección y el desahogo del usuario en un entorno seguro y privado.

A diferencia de un simple chat, MindBridge actúa como un espejo: rebota tus ideas para ayudarte a entender tus propios sentimientos. Sin embargo, su característica más importante es su **Módulo de Seguridad Activa**: el sistema monitorea patrones de riesgo en tiempo real. Si detecta ideación suicida, crisis agudas o temas que exceden su capacidad de "coaching", bloquea el chatbot y activa un protocolo de triaje para conectar al usuario con profesionales humanos inmediatamente.

## Objetivos del Proyecto

El sitio tiene como meta que el usuario comprenda y diferencie las herramientas de salud mental:

1.  **Higiene Mental Diaria:** Proveer una herramienta de "limpieza mental" para ordenar el ruido de los pensamientos cotidianos mediante la escritura y el feedback inteligente.
2.  **Red de Seguridad:** Demostrar que la IA puede actuar como un primer filtro de contención, detectando cuándo la introspección no es suficiente y se requiere intervención clínica.
3.  **Desestigmatización:** Normalizar el paso del "desahogo" a la "terapia" mediante un puente suave y sin fricción hacia un marketplace de psicólogos.

## Funcionalidades Principales

* **Chat de Introspección (AI Journal):** Un chatbot entrenado para hacer preguntas reflexivas y resúmenes de sentimientos, no para dar consejos clínicos.
* **Dashboard Emocional:** Visualización de datos (gráficos semanales, nubes de palabras) para que el usuario identifique patrones en su estado de ánimo.
* **Protocolo de Seguridad (Kill Switch):** Detección automática de palabras clave o sentimientos de alto riesgo que desactiva la IA y redirige a ayuda humana.
* **Marketplace de Profesionales:** Un directorio integrado para agendar citas con psicólogos cuando el usuario (o el sistema) lo considere necesario.

## Estructura del Sitio Web

El proyecto se divide en las siguientes secciones clave para la navegación del usuario:

### 1. Página Principal (`index.html` / Landing)
* **Introducción:** Propuesta de valor ("Donde tus pensamientos encuentran orden").
* **Disclaimer Ético:** Aclaración visible de que la herramienta no reemplaza a un psicólogo.
* **Accesos:** Rutas diferenciadas para usuarios y profesionales de la salud.

### 2. Funcionalidades y Métricas (`/features`)
* **Demo del Diario:** Explicación técnica de la interacción con la IA.
* **Tu Mente en Datos:** Muestra del dashboard de análisis emocional y seguimiento semanal.

### 3. Red de Ayuda (`/help` - Marketplace)
* **Directorio:** Perfiles de psicólogos aliados, especialidades y agenda.
* **Triaje:** Sección a la que se redirige al usuario en caso de emergencia o detección de riesgo.
* **Recursos de Urgencia:** Botones de llamada rápida a líneas de vida nacionales.

### 4. Sobre Nosotros (`/about`)
* **Misión:** La filosofía detrás de democratizar la introspección.
* **Privacidad:** Explicación detallada sobre la encriptación de datos y el anonimato de las sesiones de chat.

---

## ⚠️ Disclaimer Importante

**MindBridge NO es un sustituto de la terapia psicológica profesional.**
Esta herramienta es un recurso de autoayuda y registro personal. El sistema está programado para priorizar la seguridad del usuario y restringir su uso ante la detección de crisis, derivando inmediatamente a servicios de emergencia o profesionales cualificados.
